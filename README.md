# 🛒 Smart Cart - Tela de Login

Interface de login moderna e responsiva desenvolvida para o ecossistema **Smart Cart**. Este projeto foi construído do zero focando em boas práticas de HTML5 semântico, acessibilidade e estilização CSS estruturada.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica (`<main>`, `<header>`, `<form>`, `<button>`).
- **CSS3:** Layout responsivo construído com **Flexbox**, estilização de formulários e animações interativas.
- **SVG / Vetores:** Ícones escaláveis para melhor performance e qualidade visual.

---

## 🎨 Funcionalidades e Destaques

- **Layout Centralizado:** Alinhamento preciso dos elementos utilizando `flexbox`.
- **Efeitos de Hover & Focus:** Animações e transições suaves ao interagir com os campos e botões.
- **Acessibilidade:** Estruturação correta dos tipos de campos (`type="email"` e `type="password"`).
- **Design Limpo:** Remoção de elementos nativos desnecessários dos navegadores via CSS.

---

## 📂 Como visualizar o projeto

1. Clone este repositório ou baixe os arquivos em `.zip`.
2. Abra o arquivo `index.html` em qualquer navegador web.
